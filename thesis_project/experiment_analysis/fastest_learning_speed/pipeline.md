# FASTEST LEARNING SPEED PIPELINE (Section 5.3)
 
## 1.Overview

This pipeline computes the learning-speed (sample-efficiency) metric used in
Section 5.3 of the thesis. The goal is to determine how quickly different
hyperparameter configurations enable an algorithm to reach a task-specific
target reward.

For each training run, the metric is defined as the earliest evaluation
timestep at which the mean evaluation return reaches or exceeds a predefined
threshold R_target. Runs that never reach the threshold within the training
budget are marked as unsuccessful.

## 2.Data Sources

### 2.1 Experiment root directory

All experiment logs are stored under:
```

    <PROJECT_ROOT>/runs/<ENV>/<ALGO>/<RUN_ID>/

Example:

    /homes/sohawan2/reinforcement-learning-thesis/thesis_project/
    runs/Hopper-v4/a2c/20251107_171248_728087_pid2961473_seed0
```

### 2.2 Required files per run

Each run directory must contain the following files:

```
2.2.1 eval/evaluations.npz

      Contains evaluation results produced during training.
      Required arrays:
        - timesteps: environment steps at which evaluations occur
        - results: per-episode evaluation returns

2.2.2 config.yml
      Contains metadata and the hyperparameter configuration of the run,
      including environment name, algorithm, seed, and hyperparameters.


Other files (progress.csv, monitor.csv, checkpoints, etc.) are not used by this pipeline.
```

## 3.Inputs and Constants

### 3.1 Run root path

RUNS_ROOT:
/homes/sohawan2/reinforcement-learning-thesis/thesis_project/runs

### 3.2 Target reward thresholds

A fixed target reward R_target is defined per environment:

```
3.2.1 CartPole-v1
      R_target = 475

3.2.2 LunarLander-v3
      R_target = 200

3.2.3 LunarLanderContinuous-v3
      R_target = 200

3.2.4 Hopper-v4
      R_target = 2000

```

### 3.3 Evaluation statistics

For each evaluation point i:
mean_return[i] = mean(results[i, :])

## 4.Processing Pipeline

The pipeline is executed via:

python run_pipeline.py


It consists of two sequential stages.

### 4.1 Stage 1: Run-level metric computation

#### 4.1.1 Run discovery

Recursively scan RUNS_ROOT for directories matching:

      RUNS_ROOT/<ENV>/<ALGO>/<RUN_ID>/


#### 4.1.2 Evaluation loading

For each run directory:
- locate eval/evaluations.npz
- skip the run if the file is missing or unreadable

#### 4.1.3 Threshold evaluation

For each valid run:

  ##### 4.1.3.1 Load evaluation arrays

          - load timesteps
          - load results
          - compute mean_returns

  ##### 4.1.3.2 Threshold crossing detection

          - find the smallest index i such that:
                mean_returns[i] >= R_target

  ##### 4.1.3.3 Learning-speed assignment

          - if such index exists:
                T_to_target = timesteps[i]
                success = True
          - otherwise:
                T_to_target = undefined (NaN)
                success = False


#### 4.1.4 Run metadata extraction
For each run:
- environment name
- algorithm name
- random seed
- run directory path
- parsed hyperparameters from config.yml

#### 4.1.5 Run-level result storage

Store one record per run containing:
- env
- algo
- seed
- run_dir
- T_to_target
- success flag
- hyperparameters

  All records are written to:

    fastest_learning_runs_full.csv

### 4.2 Stage 2: Environment–algorithm aggregation

#### 4.2.1 Load run-level dataset
Read fastest_learning_runs_full.csv.

#### 4.2.2 Success-rate computation
For each (ENV, ALGO) pair:
- num_total: total number of runs
- num_success: number of successful runs
- success_rate = num_success / num_total

#### 4.2.3 Fastest-run selection
For each (ENV, ALGO) pair:
- consider only successful runs
- select the run with minimal T_to_target
- extract:
* fastest T_to_target
* run directory
* seed
* hyperparameter configuration

#### 4.2.4 Aggregated result storage
Write one summary record per (ENV, ALGO) pair to:

    fastest_learning_by_env_algo.csv


#### 4.2.5 Console reporting
Print success rates and fastest configurations for quick inspection.

## 5.Output Files

### 5.1 fastest_learning_runs_full.csv
Run-level dataset containing learning-speed metrics for all runs.

### 5.2 fastest_learning_by_env_algo.csv
Aggregated dataset used to construct tables and figures in Section 5.3.

### 5.3 success_rate.png (optional)
Bar chart visualising success rates across environments and algorithms,
generated by plot_success_rate.py.

## Execution Summary

### 6.1 Required command
python run_pipeline.py

### 6.2 Optional plotting
python plot_success_rate.py

## 7.Assumptions and Notes

### 7.1 Learning speed is computed from evaluation returns, not training returns.

### 7.2 Only the first threshold crossing is considered.

### 7.3 Runs that never reach R_target are excluded from fastest-run selection but
included in success-rate statistics.

### 7.4 If multiple runs share the same minimal T_to_target, the selected run
depends on the internal ordering of the dataset.
